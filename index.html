文件同步

适合手机与电脑。JSON 本质上是纯文本，可直接用文本编辑器修改。

提示：GitHub Pages 是静态网站，浏览器不能无授权自动改写仓库里的文件。因此“导出 → 替换仓库文件 → 其他设备读取”是最稳妥的无服务器方案。

直接编辑纯文本

可以复制这段 JSON 到任何文本文件中；修改后点“应用文本数据”。

电脑端增强：绑定本地文件

Chrome / Edge 支持直接选择一个 JSON 文件。绑定后可一键读写；Safari/iPhone 通常不支持此能力。
